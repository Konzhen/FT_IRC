# FT_IRC

Serveur IRC écrit en C++. Le projet gère les connexions de clients, les salons et les commandes du protocole implémentées dans cette version.

## Compilation et lancement

    make
    ./ircserv port mot_de_passe

Le serveur écoute sur le port indiqué. Un client IRC peut ensuite s’y connecter avec le mot de passe fourni au lancement.
